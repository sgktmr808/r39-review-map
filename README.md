# R39 レビューマップ

球体都市 R39 の**平面図に区画を切り、修正・追加の要望を登録してファイルへ書き出す**ための 1 ページアプリ。

## 使い方

ローカルで開くだけで動く。`fetch` を使うので **file:// では動かない**。簡易サーバを立てる。

```bash
python3 -m http.server 8080
# → http://localhost:8080 を開く
```

1. 地図の区画をクリックして選ぶ(複数可。もう一度押すと解除)
2. 「追加実装レビュー」または「修正レビュー」に書いて登録
3. 「レビューをファイルへ書き出す」で JSON がダウンロードされる
4. その JSON を実装側へ渡す

登録内容は localStorage に残るので、閉じても消えない。

## 区画

20 列(A–T)× 10 行(1–10)。1 区画 196.3 m 四方。
地図の実寸は 3927 m × 1963 m。

投影は**アプリの平面モード(morphT=0)と同一**なので、区画はアプリを平面へモーフしたときの位置とそのまま一致する。

## 地図に描いてあるもの

- 地形(標高で着色)・海・湖・運河
- 河川(中心線を強調)
- 道路(幹線 / 補助幹線 / 生活道路で明度を分けている)
- 鉄道(橙)・地下鉄(紫)
- 点要素(切替可能): 都市 / 地区 / 山 / 港 / 鉄道駅 / 地下鉄駅 / ランドマーク / 河川の源流と河口 / ヨットハーバー(仮設)

## 書き出される JSON

```json
{
  "schema": "r39-review/1",
  "world": { "radiusM": 625, "seed": 777, "seamLonRad": -0.89, "seamLonDeg": -51 },
  "reviews": [
    { "id": 1, "kind": "add", "priority": "high",
      "cells": ["D3"], "point": { "lat": 39.9, "lon": 70.8 },
      "inCells": ["marina-provisional"],
      "title": "…", "body": "…" }
  ]
}
```

`world` が入るので、**古い世界に対するレビューかどうかを実装側が判定できる**。
`inCells` はその区画に入っている地物の ID なので、何を指しているかが曖昧にならない。

## 更新

世界が変わったら、生成側リポジトリで書き出し直して `map.png` と `manifest.json` を差し替える。
